# Toolbox 首页与网易云快捷下载设计

## 目标

将 Toolbox 从单工具页面改为首页入口。首页展示工具卡片；当前首个工具为“网易云音乐歌单”。左键进入工具页，右键打开该工具的快捷菜单。

## 导航与工具注册

- 应用内部维护 `home` 与 `ncm` 两个视图，不引入路由依赖。
- 首页以工具注册表渲染卡片，卡片包含名称、简介、图标和快捷操作定义；后续新增工具只需增加一个注册项。
- 左键卡片切换至 `ncm` 视图。
- 工具页页头包含“返回首页”。登录状态保持在 App 层，切换视图不丢失。

## 右键快捷菜单

- 在工具卡片右键时阻止浏览器默认菜单，在指针位置显示浮层菜单。
- 点击页面其他位置、按 Escape 或选择菜单项后关闭菜单。
- 网易云工具提供“解析歌单并下载所有未下载歌曲”。

## 快捷下载流程

1. 选择快捷操作后打开弹窗，输入框预填最后使用的歌单分享链接，且可编辑。
2. 解析弹窗输入的歌单，计算本地下载记录以筛出未下载歌曲。
3. 弹窗展示歌单名、待下载数量，以及前若干首歌名/歌手；待下载为空时显示无须下载。
4. 用户点击确认后，调用现有下载队列开始下载；用户取消则不下载。
5. 未登录时，确认操作提示需要扫码登录且不开始下载。

## 状态与数据

- 最后使用的歌单链接存到 localStorage；工具页解析成功后更新它。
- 下载状态和现有的 `ncm_downloaded_ids` 记录保持兼容。
- 快捷下载复用歌单详情、歌曲详情、登录校验、下载队列和音质选择；不新增第二套下载实现。

## 错误处理

- 无法解析链接、歌单请求失败或没有待下载歌曲均在弹窗内显示明确提示，且不执行下载。
- 下载中的错误仍交由既有任务队列记录与展示。
