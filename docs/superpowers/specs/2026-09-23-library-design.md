# 图书馆工具设计

## 目标

在 Toolbox 中新增“图书馆”工具，用于管理 `~/important/books` 下的本地书籍。它递归展示 `Library` 中的原书，持久化管理优先级、类型和长描述，并通过 `read` / `unread` 中的 Windows `.lnk` 快捷方式反映阅读状态。

## 目录与身份模型

配置的固定根目录如下：

| 用途 | 路径 |
| --- | --- |
| 原书根目录 | `~/important/books/Library` |
| 未读快捷方式 | `~/important/books/unread` |
| 已读快捷方式 | `~/important/books/read` |

`~` 由后端在运行时解析为当前登录用户的主目录（Windows 上即 `%USERPROFILE%`），不会在代码或数据库中写死某个用户名。数据库记录的是解析后的绝对路径，保证对同一用户的扫描、快捷方式解析和元数据关联一致。

`Library` 是唯一的原书来源。每次打开图书馆页面时，后端都递归扫描其全部子目录，所有常规文件都作为图书显示。图书的稳定身份是规范化后的原书绝对路径，标题由文件名去除扩展名得到。

`read` 和 `unread` 仅保存指向原书的 `.lnk`，并镜像 Library 的相对目录结构。譬如 `Library/灌篮高手/1.pdf` 的未读快捷方式是 `unread/灌篮高手/1.lnk`；标记已读后成为 `read/灌篮高手/1.lnk`。扫描这些快捷方式并解析目标路径，以确定已读状态；失效快捷方式不显示为图书。若同一本书意外同时存在于两个状态目录，后端将返回明确错误并要求用户先修复冲突，而不是静默猜测状态。

## 持久化

使用应用数据目录中的 SQLite。图书元数据表以原书绝对路径为主键，包含：

- `book_path`：原书绝对路径；
- `priority`：整数 0 到 5；
- `book_type`：可空字符串；
- `description`：可空长文本；
- `updated_at`：最后编辑时间。

扫描到的新书以默认元数据创建；扫描中已不存在的原书的元数据记录会删除。状态不在数据库中保存，而是每次由快捷方式扫描得出，因此目录状态始终为准。

## 后端职责

新增 Rust `library` commands 模块并在 Tauri command handler 中注册。它负责：

1. 初始化/迁移 SQLite 表；
2. 递归扫描 `Library`，建立可折叠的目录树并合并元数据和阅读状态；
3. 更新优先级、类型、描述；
4. 将已读状态改为已读或未读：仅在确认后的 command 调用中创建/移动 `.lnk`，按需创建目标状态目录中的镜像子目录，随后递归删除源状态目录中已空的子目录（不删除 `read` 或 `unread` 根目录），绝不移动原书；
5. 用系统默认程序打开原书；
6. 删除原书、`read` 和 `unread` 两边对应的快捷方式及元数据。

快捷方式目标的读取与创建采用 Windows API / PowerShell 的受控实现，并在每次写入前验证目标仍位于 `Library` 根目录内。状态迁移和删除以“先完成文件系统操作，再更新数据库”的顺序执行；失败会返回结构化错误，避免前端显示未实际完成的状态。

## 前端界面

新增 `library` 工具定义和图书馆页面。打开页面立即执行刷新并显示扫描中状态。顶部工具栏包含：

- 关键词搜索：标题、类型和描述；
- 星级筛选；
- 全部 / 已读 / 未读筛选；
- 类型筛选；
- “仅有描述”开关；
- 手动刷新。

结果区是保持 Library 文件夹关系的可折叠树。文件夹可展开/折叠；筛选或搜索后，只显示匹配的书及其必须的父文件夹。排序支持标题、优先级、已读、类型、描述五个字段，且只重排每一个目录中的直接书籍，绝不把图书移离目录层级。

书籍行显示并编辑下列字段：

| 字段 | 交互 |
| --- | --- |
| Title | 只读文件名，旁有“打开”按钮 |
| Priority | 0–5 星可点选 |
| 已读 | 复选框 |
| Type | 内联文本输入 |
| Description | 预览、展开和长文本编辑 |
| 操作 | 删除按钮 |

编辑元数据后立即保存。改变已读复选框时先弹出确认对话框；取消或失败则恢复原显示状态。点击删除同样先确认，确认文案明确列出它将删除 Library 原书、两处快捷方式和元数据。

## 错误与边界

- 根目录不可读取时提供清晰错误和重试入口；
- 原书在操作前已消失时阻止操作并建议刷新；
- 文件被占用、无权限或快捷方式创建失败时显示后端错误且不乐观更新；
- 打开、删除、状态迁移均重新验证路径位于 Library；
- `.lnk` 指向 Library 外文件或失效时忽略，绝不对外部路径执行删除或移动。

## 非目标

本期不提供新增/导入图书、跨库搜索、云同步、封面抓取或批量编辑。目录由用户现有的固定位置管理。
