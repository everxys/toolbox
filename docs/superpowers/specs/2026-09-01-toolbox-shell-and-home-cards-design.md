# Toolbox 公共导航与首页卡片设计

## 目标

统一 Toolbox 内所有工具页的返回首页入口，并优化首页工具卡片在工具数量增加后的布局与图标缩放体验。

## 公共工具页外壳

- `App` 负责渲染非首页视图的公共顶部栏；当前和未来的每个工具页都自动获得左上角的“← 回到首页”按钮。
- 该按钮调用 App 的视图切换回调，切换回 `home`；工具组件不再接收或渲染 `onBackHome`。
- 顶部栏位于工具内容之前，与工具自身标题、筛选和分页区域分离。

## 网易云歌单工具

- 删除工具标题行中原有的“返回首页”按钮，避免与公共顶部栏重复。
- 分页区域保留当前会将页码设为 `1` 的按钮，但文案改为“回到第一页”。
- “上一页”“下一页”“回到第一页”仅操作歌单页码，不改变 App 视图。

## 首页工具卡片

- 首页卡片为方形，使用响应式网格展示；每张卡片保持相同宽高，图标、名称和简介在卡片内居中排布。
- 用户仅在首页按住 `Ctrl` 并滚动鼠标滚轮时，调整工具图标的显示大小；上滚放大、下滚缩小。
- 图标大小有最小值和最大值，越界时保持边界值。普通滚轮仍执行页面滚动；工具页内的 `Ctrl` + 滚轮不改变首页图标大小。
- 图标大小保存在 `localStorage`，重新打开 Toolbox 后恢复；无保存值或保存值无效时使用默认大小。

## 事件与可访问性

- 首页仅在 `Ctrl` + 滚轮确实改变图标大小时阻止默认滚动；每次变化后提供简短的可见说明文字，告知当前图标大小和快捷操作。
- 右键快捷菜单、左键进入工具和菜单关闭行为保持不变。

## 验证

- 为图标大小的加载、保存、边界裁剪和 Ctrl+滚轮增减写纯函数测试。
- 为分页“回到第一页”保留纯页码行为测试。
- 运行 Node 测试、TypeScript 检查、前端构建、Rust 测试，并重新构建无安装包 EXE。
- 手工验证：首页缩放、持久化、公共返回首页入口、网易云分页按钮和右键菜单。
